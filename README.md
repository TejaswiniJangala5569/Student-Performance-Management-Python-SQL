# Student-Performance-Management-Python-SQL
Student Perfoemance Management System using Python and SQL


## Project Overview

This project is a simple Student Performance Management System developed using Python and SQL.

The project stores student information in a SQLite database and uses SQL queries to analyze student performance.

## Technologies Used

- Python
- SQL
- SQLite
- Jupyter Notebook
- Pandas
- Matplotlib

## Features

- Store student records
- Display student information
- Search students
- Find top-performing students
- Calculate average marks
- Analyze attendance
- Analyze course-wise performance
- Grade distribution
- Update student marks
- Delete student records
- Visualize student marks

## Database

SQLite is used as the database, so no separate SQL application is required.

## Dataset

The project contains 100 student records generated directly using Python.

No CSV file is used.

## How to Run

1. Download or clone this repository.
2. Open `Student_Performance_Management_Python_SQL.ipynb` in Jupyter Notebook.
3. Run the cells in order.
4. The SQLite database will be created automatically.
